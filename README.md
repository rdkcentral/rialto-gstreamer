## Building and Running Unit Tests:
https://wiki.rdkcentral.com/display/ASP/Unit+Tests

The [unit-test workflow](.github/workflows/build_ut.yml) compares coverage with
Master only for PRs targeting `master`. It posts the generated report even when
coverage decreases and fails the comparison. Release PRs still generate and
upload coverage statistics, but do not perform or comment on a baseline comparison.
